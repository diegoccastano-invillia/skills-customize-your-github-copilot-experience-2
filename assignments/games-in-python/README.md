
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Preparar a palavra secreta

#### Descrição
Selecione uma palavra aleatoriamente de uma lista predefinida e prepare a exibição inicial do jogo, ocultando as letras que ainda não foram adivinhadas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Mostrar cada letra não descoberta como um espaço em branco, por exemplo, `_ _ _`.

### 🛠️ Conduzir a partida

#### Descrição
Receba palpites de letras, atualize a palavra exibida e controle as tentativas até o jogador adivinhar a palavra ou ficar sem tentativas.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras e revelar todas as ocorrências corretas na palavra.
- Rastrear e atualizar o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
